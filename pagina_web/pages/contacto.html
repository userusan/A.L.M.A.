Preguntas frecuentes

Resolvemos tus dudas

¿Quién puede utilizar A.L.M.A.?

Está pensada principalmente para personas adultas mayores y para quienes forman parte de su red de cuidado. También contempla una modalidad para instituciones.

¿A.L.M.A. sustituye a un médico?

No. Es una herramienta de acompañamiento y no sustituye consultas, tratamientos ni diagnósticos profesionales.

¿A.L.M.A. puede diagnosticar Alzheimer?

No. Las actividades cognitivas tienen una finalidad de estimulación y acompañamiento.

¿Necesito saber utilizar mucho la tecnología?

El proyecto busca reducir esa dificultad mediante una interfaz sencilla y la posibilidad de interactuar por voz.

¿Necesita internet?

Las funciones que requieren comunicación con la nube, sincronización o envío de alertas necesitan conexión a internet. El prototipo actual contempla el uso de un smartphone compatible y conexión a internet.

¿Cómo funciona la ubicación?

La ubicación se obtiene mediante el dispositivo y se utiliza de acuerdo con los permisos otorgados y dentro de la red autorizada.

¿Qué es una geocerca?

Es una zona virtual establecida sobre un lugar real. Puede utilizarse para configurar zonas de seguridad y generar alertas ante determinados eventos.

¿Quién puede consultar la información del adulto mayor?

El acceso se plantea de acuerdo con los roles y permisos establecidos dentro del sistema.

¿A.L.M.A. vigila al adulto mayor todo el tiempo?

No. El propósito es proporcionar herramientas de acompañamiento y seguridad respetando la autonomía de la persona.

¿A.L.M.A. ya está disponible para todo el público?

Actualmente se encuentra en etapa de prototipo funcional y validación. Todavía no se presenta como un producto comercial disponible para el público general.
